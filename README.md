## 🚀 1. Iniciação (Milestone 1)

### Contexto do Problema
O setor das telecomunicações enfrenta uma concorrência agressiva. Este projeto foca-se na identificação de padrões que levam ao abandono de clientes (**Churn**), permitindo à gestão implementar estratégias de retenção eficazes e reduzir perdas financeiras.

### Objetivos SMART
* **Objetivo 1:** Desenvolver um modelo preditivo com um **F1-Score superior a 0.75** até ao final da Milestone 3.
* **Objetivo 2:** Identificar as 3 principais variáveis que influenciam a saída dos clientes para apoiar decisões de marketing.

### Fonte de Dados
* **Dataset:** Telco Customer Churn (Disponível no [Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)).
